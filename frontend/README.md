# NearYou – Frontend

A Web-Based Roadside Support Platform built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Project Overview

Roadside vehicle breakdowns are a critical issue for drivers and travelers. **NearYou** provides an on-demand, location-based service platform connecting vehicle owners directly with nearby verified mechanics in real time.

### Key Capabilities:
- **Two-Sided Platform**: User and Mechanic portals with role-tailored dashboards.
- **Location-Based Search**: GPS-based search filtering by proximity, vehicle type (Bike, Car, Battery, Towing), and availability.
- **Trust & Verification**: Verified profiles, ID checks, skill validations, and administrative approvals.
- **Real-Time Updates**: Mechanic arrival tracking with live statuses (`Accepted`, `On the Way`, `Completed`).
- **Direct Communication & Reviews**: In-app communication and transparent user rating/review system.

---

## Tech Stack
- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [Radix UI](https://www.radix-ui.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router](https://reactrouter.com/)

## Getting Started

### 1. Install Dependencies

### 2. Run Development Server

### 3. Build for Production
